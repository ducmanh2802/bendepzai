# T18C — Hệ thống động lực — Shop mở rộng, thành tựu, cài đặt phụ huynh

**Spec gốc:** `docs/opencode/T18_he_thong_dong_luc.md` — **mục 5–7**

> File này là bản chính thức. Chỗ nào khác spec gốc thì làm theo file này. Luật chung: `docs/opencode/00_RULES.md`.

## Phạm vi
- Shop ≥ 40 món, mặc lên avatar (T03B), mở theo level; màn thành tựu cho ≥ 30 thành tựu.
- Cài đặt phụ huynh: giới hạn lượt máy gắp/ngày, bật/tắt phần thưởng, lịch sử phần thưởng.

## Nghiệm thu chung
- `npm run typecheck`, `npm test`, `npm run build` đều PASS (runner sẽ tự kiểm lại).
- Báo cáo `docs/opencode/reports/T18C_REPORT.md`: đã làm gì, file thay đổi, số liệu trước/sau, lệnh đã chạy + kết quả, các quyết định bạn tự đưa ra, việc còn tồn.
