# T10C — Tiếng Việt: vần nhóm 2 (ai … uynh) + từ & câu

**Spec gốc:** `docs/opencode/T10_tieng_viet_am_van.md` — **mục 4 nửa sau + mục 5**

> File này là bản chính thức. Chỗ nào khác spec gốc thì làm theo file này. Luật chung: `docs/opencode/00_RULES.md`.

## Phạm vi
Các vần: ai ay ây, oi ôi ơi, ui ưi, ao eo, au âu êu, iu ưu, ia ua ưa, iêc iên iêp iêt iêu iêm, yêu yên, uôc uôn uôt uôi uông, ươc ươn ươt ươi ương ươu, oa oe, oai oay, oan oat, oăn oăt, oang oac, oanh oach, uê uy, uân uât, uyên uyêt, uych uynh.
- Mục 5: ghép tiếng thành từ, sắp xếp câu 4–6 chữ, điền từ vào câu, chọn câu đúng với tranh.
- Quy ước như T10B. Cập nhật `docs/CURRICULUM_MAP.md`.

## Nghiệm thu riêng
- Tổng Tiếng Việt sau T10A–C: **≥ 45 bài, ≥ 450 câu** (ghi bảng số liệu).

## Nghiệm thu chung
- `npm run typecheck`, `npm test`, `npm run build` đều PASS (runner sẽ tự kiểm lại).
- Báo cáo `docs/opencode/reports/T10C_REPORT.md`: đã làm gì, file thay đổi, số liệu trước/sau, lệnh đã chạy + kết quả, các quyết định bạn tự đưa ra, việc còn tồn.
